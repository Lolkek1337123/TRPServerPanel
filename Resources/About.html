Core Orchestrator

Ядро системы, отвечающее за запуск сервера, автоматическое восстановление при крашах и управление процессом RustDedicated.exe. Содержит встроенную систему валидации портов и путей.

TRP AI Shield

Уникальная система безопасности на базе Nemotron 120B. Проверяет плагины на наличие скрытых WebRequests, бэкдоров и кражи RCON. Позволяет мгновенно исправлять уязвимости в коде.

Live Monitoring

Система телеметрии в реальном времени. Отслеживает нагрузку на CPU, RAM и активность игровых потоков через RCON-мост собственной разработки.

Integrated Marketplace

Единая точка доступа к плагинам uMod и эксклюзивам TRP. Автоматическая установка с определением фреймворка (Oxide/Carbon) и загрузкой зависимых библиотек.

Аналитика Zero-Plugin

Панель читает статистику напрямую из базы данных SQLite сервера. Нам не нужны плагины внутри игры для сбора базовой аналитики, что экономит ресурсы вашего сервера.

ИИ-Защита (AI Shield)

Сканер анализирует C# код на подозрительные вызовы. Используйте кнопку 'Исправить через ИИ' для автоматического патча небезопасного кода.

Управление Конфигами

Все настройки плагинов находятся в папке config. При сохранении файла через панель, плагин автоматически перезагрузится на сервере.

База Знаний / Documentation

Структура папок и ГДЕ ЧТО МЕНЯТЬ

/plugins

Здесь лежат .cs файлы. Добавьте файл сюда, и он автоматически загрузится.

/config

JSON настройки. Каждый плагин создает свой файл настроек здесь.

/data

Базы данных плагинов. Здесь хранятся экономики, уровни и история.

КАК ЭТО РАБОТАЕТ

Панель TRP использует гибридную архитектуру. Интерфейс на HTML/JS взаимодействует с системным ядром на C# через высокоскоростной мост.

Чтение данных (Analytics): Мы используем journal_mode=OFF для доступа к SQLite файлам Rust (deaths.db, identities.db) в режиме 'ReadOnly'. Это позволяет избежать блокировки базы данных игрой.

Управление (RCON): Панель подключается к серверу по протоколу WebSocket. Если RCON недоступен, команды отправляются напрямую в процесс StandardInput.

Файлы заблокированы (Access Refused)

Если вы видите ошибку 'Access to path is denied', значит процесс Rust или Carbon все еще запущен в фоне. Завершите его через диспетчер задач перед установкой ядра.

Обновление Carbon через панель

Всегда перезагружайте сервер после установки обновлений в Marketplace. Большинство изменений вступают в силу мгновенно, но ядро требует перезапуска.

Ложные срабатывания AI Shield

ИИ может пометить WebRequest как опасный, если он ведет на незнакомый домен. Если вы уверены в плагине - просто проигнорируйте предупреждение в логах.

Пропала консоль приложения

Нажмите кнопку 'Логи' в футере приложения. Там отображаются все внутренние запросы между UI и логикой сервера.
